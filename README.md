# Personal site

Built with [Zola](https://www.getzola.org) 0.23.6 and published to GitHub Pages on every push to `main`.

- `zola serve` to preview locally, `zola build` to build into `public/`
- Text lives in `content/`, site settings in `zola.toml`
- `backend/Code.gs` is a copy of the Apps Script behind the contact form, poll and résumé
